Compact metric tile for learner & educator dashboards.

```jsx
<KpiCard label="Accuracy" value="92%" tone="purple" icon={<Target size={16}/>} />
```

Tinted top accent + big numeral. Tones: blue/green/gold/purple/orange. `value` accepts strings like "2h 30m". Lay out in a CSS grid (2-up on mobile, 4-up on tablet).
