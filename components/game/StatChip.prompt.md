Glossy balance pill for gamification totals — shown in headers and reward screens.

```jsx
<StatChip kind="coin" value={250} />
<StatChip kind="streak" value="5 Days" size="lg" />
```

Kinds: `coin` (gold), `star` (yellow), `xp` (green), `streak` (flame), `custom` (pass `glyph`). Sizes `sm`/`md`/`lg`. `value` accepts strings like "2h 30m".
