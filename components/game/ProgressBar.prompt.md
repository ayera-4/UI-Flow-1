Rounded glossy progress track for skill mastery, the splash loader, and accuracy readouts.

```jsx
<ProgressBar value={90} tone="green" label="Counting Money" showValue />
```

Tones: green/blue/orange/gold/purple/red. Sizes `sm`/`md`/`lg`. `label` renders above, `showValue` adds a right-aligned %. Fill animates on value change.
