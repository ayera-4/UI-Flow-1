Soft, very-rounded container — the workhorse surface. Tinted tones reproduce the level/tier-card pattern.

```jsx
<Card tone="purple" pad="md" interactive>Level 3 — Advanced</Card>
```

Tones: `paper` (warm white, default), `white`, and tints `green`/`yellow`/`purple`/`blue` (beginner→advanced tiers). `pad`: none/sm/md/lg. `raised` toggles shadow vs hairline border. `interactive` lifts on hover.
